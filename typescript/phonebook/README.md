## 소감
### 웹팩
cra 없이 리액트를 웹팩으로 설정하니 정말 어려웠다. cra는 자동으로 웹팩 설정을 해주지만 필요하지 않은 설정이나
<br> 라이브러리도 있기때문에 최적화를 위해서 불편하더라도 cra 없이 웹팩으로 연습 해야겠다.

### 리액트
usecallback usememo 등등 코드스플릿 최적화에 대한 것들을 많이 배웠다. 왜최적화를 해야하는지 알았고  어떤 원리로 최적화가 되는지 알 수 있었다.
### swr
원격 데이터 fetch를 위한 모듈이다.
원격서버의 상태를 가져와서 React 컴포넌트에 준다. 리덕스처럼 전역상태관리를 해줄 뿐만아니라 실시간업데이트를 해준다.
redux보다 코드도 적고 간편해서 좀더 연습해서 swr로 갈아타야겠다.

### socket.io
쉽게말하면 문자처럼 내가 요청하지 않아도 응답을 받을 수 있게 해준다. <br>
그렇게하기위해선 프론트와 서버를 계속 연결 시켜놓는거다. 특정 메세지가오면 그메세지에 맞는 api와 계속 연결 시켜주는 개념이다
백엔드 부분도 공부하고 제대로 공부해봐야겠다.
