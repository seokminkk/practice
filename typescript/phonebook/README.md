## 목적

## 사용스택
### 리액트,타입스크립트, 리덕스 툴킷, 리덕스 퍼시스트

## 소감
### 타입스크립트
리액트랑 사용하면서 상당히 어려웠다. 타입을 설정해주지 못하고 any로 넘긴 적도 많다. 
리액트의 타입도 ex) React.ChangeEvent<HTMLInputElement> 설정해줘야했고 props를 넘기는것도 타입을 지정해줘야하고 라이브러리 설치시 
타입스크립트를 자동으로 적용해주지 않으면 @types로 설치해야했고 처음이라 좋다는 느낌보다 불편한 느낌이 들었다.
그래도 바로바로 이런것때메 안되요 라고 에러를 알려주었다.
연습이 많이 필요할 것 같다.

### 리덕스 툴킷
기본 리덕스만쓰다가 이참에 툴킷도 써보자 해서 써봤다.
Create react app 처럼 자동으로 리덕스랑같이쓰는 미들웨어나이것저것 같이 설치해주는건데 상당히 편하고 좋았다.
액션을 안만들어도 되고 combinereducer로 안묶어도 바로 configurestore에 다 집어 늘수있다.

### 리덕스 퍼시스트
툴킷이랑 같이 어떻게 써야하나 해서 써봤다. 기존의 리덕스랑 사용한것처럼 별 다를 것 없었다.
